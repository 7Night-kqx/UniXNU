# Rongyue E5 (e5)

A community device port for UMS9621.

- [Enceka/UniXNU-e5](https://github.com/Enceka/UniXNU-e5)
- [Enceka/unixnu-ums9621](https://github.com/Enceka/unixnu-ums9621)
- [Enceka/unixnu-e5-kernel-builder](https://github.com/Enceka/unixnu-e5-kernel-builder)

## State

The format 2 board selects shared UMS9621 support, ArmDTPlatform, ArmCpu and a RAM block device. The source describes eight Cortex-A53 cores, GICv3, PSCI SMC and a 26 MHz timer. Early-entry and MMU-transition probes are in development.

Use the board's own UEFI/DarwinBoot path and the pinned SoC feed. Storage, display, input and sustained XNU execution require device validation.

## Use this port

1. Read the pinned instructions and records below. Prepare the firmware, system inputs and build tools they specify.
2. Clone the device sources and prepare the matching core and firmware checkouts described by its README:

```sh
git clone --branch main https://github.com/Enceka/UniXNU-e5.git
cd UniXNU-e5
git checkout b73c144ecb19c07e287f7a5c59ebcd7c72edfefa
git submodule update --init --recursive
```

3. Run the build from the working directory specified by that revision's instructions. Check its documented outputs and remaining inputs.
4. Follow the [bring-up order](/porting/bring-up), save [logs](/porting/log-capture) and complete the [porting record](/porting/records). See [porting steps](/porting/steps) for board structure and component selection.
