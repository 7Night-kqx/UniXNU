# OnePlus 8 Pro (instantnoodlep)

OnePlus 8 Pro (instantnoodlep) is a SM8250 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer |
| --- | --- |
| [UniXNU-instantnoodlep](https://github.com/zhangp996/UniXNU-instantnoodlep) | [zhangp996](https://github.com/zhangp996) |

## State

The repository contains a UEFI platform and a kernel baseline. It does not document a hardware result.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
