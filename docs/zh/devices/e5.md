# Rongyue E5（e5）

UMS9621 社区设备移植。

- [Enceka/UniXNU-e5](https://github.com/Enceka/UniXNU-e5)
- [Enceka/unixnu-ums9621](https://github.com/Enceka/unixnu-ums9621)
- [Enceka/unixnu-e5-kernel-builder](https://github.com/Enceka/unixnu-e5-kernel-builder)

## 当前状态

格式 2 板级选择共享 UMS9621 支持、ArmDTPlatform、ArmCpu 和内存块设备。源码描述八个 Cortex-A53 核、GICv3、PSCI SMC 和 26 MHz 定时器，早期入口和 MMU 切换探针正在开发。

使用该板的 UEFI/DarwinBoot 路径及固定版本的 SoC feed。存储、显示、输入和持续 XNU 执行仍需设备验证。

## 使用此移植

1. 阅读下方固定版本的说明和记录，准备对应的固件、系统输入与构建工具。
2. 克隆设备源码，并按其 README 准备匹配的主仓库和固件源码：

```sh
git clone --branch main https://github.com/Enceka/UniXNU-e5.git
cd UniXNU-e5
git checkout b73c144ecb19c07e287f7a5c59ebcd7c72edfefa
git submodule update --init --recursive
```

3. 在该版本说明指定的工作目录执行构建，核对其记录的输出和未完成输入。
4. 按[启动验证顺序](/zh/porting/bring-up)逐项确认，通过[日志抓取](/zh/porting/log-capture)保存结果，并填写[适配记录](/zh/porting/records)。板级结构和组件选择见[移植步骤](/zh/porting/steps)。
