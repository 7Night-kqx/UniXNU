## 当前状态

格式 2 系统已在八个 CPU 上进入桌面，UFS、96 GiB 持久化 Data 和 CPU 帧缓冲渲染可用。FT8203 触控、物理电源/音量键、亮度、显示关闭/唤醒和关机均有实机记录。SM5714 电量计可报告电池状态和充电器变化。

USB 诊断包含日志、调用栈、ECM 和原生 debugserver 采集与 detach。MSC 可更新 FAT 负载并保留 OS/SystemOS 和 Data。A642L 后端和 Turnip 工具仍在源码开发，GPU 界面加速、无线、音频和系统挂起待完成。

## 使用此移植

1. 阅读上方仓库的构建说明和固定版本记录，准备对应的固件、系统镜像和板级输入。
2. 按该仓库的命令构建，通用配置见[构建与启动](/zh/building)。
3. 按[启动验证顺序](/zh/porting/bring-up)逐项验证，通过[日志抓取](/zh/porting/log-capture)保存结果。
4. 更新[移植记录](/zh/porting/records)，记录实际使用的源码版本及最后确认的阶段。
